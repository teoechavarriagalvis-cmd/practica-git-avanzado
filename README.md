## Stash
Segun lo que trabajamos con el profe Vic, git stash sirve para guardar temporalmente los cambios que tengo hechos en mi proyecto sin necesidad de hacer un commit.
Por ejemplo, si estoy trabajando en algo y necesito cambiar de rama rápidamente, puedo guardar mis cambios con stash y recuperarlos después.

## Tag
Y git tag sirve para ponerle una etiqueta a un punto específico de la historia de mi proyecto, normalmente para identificar una versión importante.
